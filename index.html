NightWin API

Скрипты для NightWin пишутся на JavaScript (ES5). Ниже собрано всё, что движок отдаёт скрипту: отрисовка поверх игры, объекты мира, своё меню, сеть, вызовы WinAPI и полный SDK игры. NightWin scripts are written in JavaScript (ES5). This page covers everything the engine exposes to a script: drawing over the game, world objects, your own menu, networking, WinAPI calls and the full game SDK.

Как устроен скриптScript structure

Движок сам вызывает эти функции, если они объявлены в скрипте. Всё остальное — обычный код. The engine calls these functions if your script declares them. Everything else is regular code. 

var shown = true;

function on_load() {
    register_tab("Hello");
    register_section("Hello", "Main");
    add_checkbox("Hello", "Main", "Show text", true);
}

function on_render() {
    if (!is_game_ready() || !shown) return;
    if (get_ui_value("Show text")) {
        draw_text(20, 20, 255, 255, 255, 255, "Hello from NightWin");
    }
}

function on_key(keycode, pressed) {
    if (pressed && keycode === 0x2E) shown = !shown; // Delete
}
is_game_ready()
Возвращает true, если игра инициализирована и готова. Returns true if the game is initialized and ready.
on_render()
Вызывается каждый кадр. Используйте для отрисовки и основной логики скрипта. Called every frame. Use for rendering and main script logic.
on_load()
Вызывается один раз при загрузке скрипта. Called once when the script is loaded.
on_key(keycode, pressed)
Вызывается при нажатии/отпускании клавиши. keycode — виртуальный код клавиши (VK_*), pressed — true если нажата, false если отпущена. Используйте для кейбиндов в скриптах. Called on key press/release. keycode — virtual key code (VK_*), pressed — true if pressed, false if released. Use for keybinds in scripts.

Что стоит знатьGood to know

  • Синтаксис ES5: var и function, без let, const, стрелочных функций и классов.ES5 syntax: var and function, no let, const, arrow functions or classes.
  • Цвет везде задаётся четырьмя числами r, g, b, a от 0 до 255.Colors are always four numbers r, g, b, a from 0 to 255.
  • Указатели на объекты — непрозрачные значения. Перед использованием проверяйте их на null.Object pointers are opaque values. Check them for null before use.
  • Имена полей и функций для get_property / call_function берите во вкладке SDK.Look up field and function names for get_property / call_function in the SDK tab.
  • Ошибки скриптов и шейдеров видны в консоли игры (F2), туда же пишет print.Script and shader errors show up in the game console (F2), where print writes too.

Rendering

Всё, что рисуется поверх игры: текст, примитивы, проекция мира на экран и свои картинки. Everything drawn over the game: text, primitives, world-to-screen projection and custom images.

Drawing

draw_text(x, y, r, g, b, a, text)
Рисует текст на экране по заданным координатам и цвету. Draws text on the screen using 2D coordinates and RGBA color.
draw_line(x1, y1, x2, y2, r, g, b, a, thickness)
Отрисовывает линию с указанной толщиной. Draws a line with custom thickness.
draw_circle(x, y, radius, r, g, b, a, segments)
Рисует круг с разбиением на сегменты. Draws a circle. Segments parameter defines complexity/smoothing.
draw_circle_3d(x, y, z, radius, r, g, b, a, segments)
Рисует 3D круг в позиции мира. Draws a 3D circle at world position.
draw_rect(x, y, w, h, r, g, b, a, thickness)
Рисует контур прямоугольника. Draws a rectangle outline.
draw_filled_rect(x, y, w, h, r, g, b, a)
Рисует залитый прямоугольник. Draws a filled rectangle.
world_to_screen(x, y, z)
Переводит 3D координаты мира в 2D координаты экрана. Возвращает {x, y} или null. Projects 3D world coordinates onto 2D screen coordinates. Returns {x, y} or null.
get_screen_center()
Возвращает 2D координаты центра экрана {x, y}. Returns the 2D coordinates of the screen center {x, y}.
get_camera_position()
Возвращает 3D координаты камеры {x, y, z}. Returns the 3D coordinates of the camera {x, y, z}.
screen_size()
Возвращает размер экрана {x, y}. Returns screen size {x, y}.
camera_angles([angles])
Получить/установить углы камеры. Без аргументов возвращает {pitch, yaw, roll}. С объектом — устанавливает. Get/set camera angles. Returns {pitch, yaw, roll} or sets if object passed.
measure_text(text[, font_size])
Возвращает размер текста {width, height}. Returns text dimensions {width, height}.
push_clip_rect(x1, y1, x2, y2[, intersect])
Начинает обрезку области рисования. Begins a clipping rectangle for drawing.
pop_clip_rect()
Завершает обрезку области рисования. Ends the current clipping rectangle.
draw_gradient(x1,y1,x2,y2, tr,tg,tb,ta, tl_r,tl_g,tl_b,tl_a, bl_r,bl_g,bl_b,bl_a, br_r,br_g,br_b,br_a)
Рисует прямоугольник с градиентом из 4 цветов по углам (top-right, top-left, bottom-left, bottom-right). Draws a rectangle with 4-color gradient at corners (top-right, top-left, bottom-left, bottom-right).
draw_circle_outline(x, y, radius, r, g, b, a, segments[, thickness])
Рисует контур круга с указанной толщиной. Draws a circle outline with custom thickness.
draw_poly_line(r, g, b, a, thickness, points_array)
Рисует ломаную линию через массив точек [{x,y}, ...]. Draws a polyline through an array of points [{x,y}, ...].
draw_poly(r, g, b, a, points_array)
Рисует залитый полигон через массив точек [{x,y}, ...]. Draws a filled polygon through an array of points [{x,y}, ...].

Images

Загрузка и отрисовка пользовательских изображений через D3D11 текстуры. Loading and rendering custom images via D3D11 textures.

load_image(buffer, width, height)
Создаёт текстуру из RGBA8 байтов (ArrayBuffer). Возвращает указатель на текстуру или null. Формат: 4 байта на пиксель (R, G, B, A). Creates a D3D11 texture from RGBA8 bytes (ArrayBuffer). Returns texture pointer or null. Format: 4 bytes per pixel (R, G, B, A).
draw_image(tex_id, x, y, w, h)
Отрисовывает загруженную текстуру на экране. Renders a loaded texture on screen.
free_image(tex_id)
Освобождает память текстуры. Вызывайте при выгрузке скрипта. Releases texture memory. Call when unloading script.

Shaders

Свои пиксельные шейдеры на HLSL: компилируются прямо в игре и рисуются в прямоугольнике экрана, по порядку с draw_*, под меню. Your own HLSL pixel shaders: compiled in game and drawn over a screen rectangle, in order with draw_*, under the menu.

shader_create(hlsl) → id | null
Компилирует шейдер с функцией main. Возвращает id или null, текст ошибки (с номером строки) пишется в консоль F2. Создавайте в on_load, не каждый кадр. Compiles a shader with a main function. Returns an id or null; the error (with its line number) goes to the F2 console. Create it in on_load, not every frame.
shader_load(file) → id | null
То же, но из файла. Относительный путь — из C:\Night\scripts\. Удобно для длинных шейдеров: в ES5 нет многострочных строк. Same, from a file. A relative path is taken from C:\Night\scripts\. Handy for long shaders: ES5 has no multi-line strings.
shader_draw(id, x, y, w, h, [params], [image])
Рисует шейдер в прямоугольнике в этом кадре (вызывайте в on_render). params — массив до 16 чисел, в шейдере это Params[0..3]. image — текстура из load_image. Учитывает push_clip_rect. Draws the shader over the rectangle this frame (call it in on_render). params is an array of up to 16 numbers, Params[0..3] in the shader. image is a texture from load_image. Respects push_clip_rect.
shader_free(id)
Освобождает шейдер. При выгрузке скрипта все его шейдеры освобождаются сами. Releases a shader. Unloading the script releases all of its shaders anyway.
shader_error() → string
Текст последней ошибки компиляции. The last compile error.
shader_attach(id, object, [params], [image]) → attachment | null
Ставит шейдер на объект в мире: актёр (все его меши) или один меш-компонент. Шейдер рисуется только там, где объект виден, и уходит за то, что перед ним. Возвращает id привязки. Тот же шейдер, что и для shader_draw. Puts the shader on an object in the world: an actor (all its meshes) or one mesh component. It is drawn only where the object is seen and goes behind whatever is in front of it. Returns an attachment id. The same shader as for shader_draw.
shader_attach_params(attachment, [params], [image])
Новые Params и картинка для привязки. Можно звать каждый кадр. New Params and image for an attachment. Fine to call every frame.
shader_detach(attachment)
Снимает шейдер, объект получает свои материалы обратно. При выгрузке скрипта это происходит само. Removes the shader; the object gets its own materials back. Unloading the script does it anyway.
shader_attach_status(attachment) → string
Что игра сделала с привязкой: "on: 1 mesh component(s)" или почему нет (объект исчез после смены карты и т.п.). What the game made of the attachment: "on: 1 mesh component(s)", or why not (the object is gone after a map change, etc.).
  • Сигнатура: float4 main(PSIn i) : SV_Target, цвет с обычной прозрачностью: float4(rgb, alpha).Signature: float4 main(PSIn i) : SV_Target, color with straight alpha: float4(rgb, alpha).
  • i.UV — 0..1 внутри прямоугольника,— 0..1 inside the rectangle, i.ScreenUV — 0..1 по экрану,— 0..1 over the screen, i.Pos — пиксель.— the pixel.
  • Time (секунды),(seconds), Rect (x, y, w, h), Screen (w, h, 1/w, 1/h), Params[4].
  • Scene — кадр игры под шейдером (блюр, искажения),— the game frame under the shader (blur, distortion), Image — картинка из— the image from load_image, Linear — сэмплер:— the sampler: Scene.Sample(Linear, i.ScreenUV).
  • ViewDir — направление взгляда через этот пиксель в мире (для неба, отражений),— the world direction of the view ray through this pixel (sky, reflections), CamPos, ViewRay(screenUV).
  • У shader_attach: Mask — насколько пиксель принадлежит объекту (прозрачность умножается на него сама), ObjCenter / ObjExtent — коробка объекта в мире, i.UV — 0..1 по его рамке на экране, MaskAt(px) — маска в другом пикселе (контуры: 1 - MaskAt(i.Pos.xy + float2(3, 0))).With shader_attach: Mask is how much the pixel is the object (alpha is multiplied by it for you), ObjCenter / ObjExtent are the object's box in the world, i.UV is 0..1 over its frame on screen, MaskAt(px) is the mask at another pixel (outlines: 1 - MaskAt(i.Pos.xy + float2(3, 0))).
  • Как это работает: на объект ставится плоский материал-ключ одного чистого цвета; шейдер рисуется только на пикселях этого цвета внутри рамки объекта. Цвет ключа выбирается сам, подальше от цветов Sky / Model Shader клиента и других привязок. Пока на том же объекте включён Sky Shader / Model Shader / картинка неба клиента, объект остаётся им — shader_attach_status это покажет.How it works: the object gets a flat key material in one pure color; the shader runs only on pixels of that color inside the object's box. The key color is picked for you, away from the client's Sky / Model Shader colors and the other attachments. While the client's own Sky Shader / Model Shader / sky image is on for the same object, the object is left to it: shader_attach_status says so.
  • Лимиты: 64 шейдера, 256 вызовов shader_draw за кадр, 4 объекта с shader_attach одновременно.Limits: 64 shaders, 256 shader_draw calls per frame, 4 objects with shader_attach at a time.

Game

Игроки и объекты мира, а также прямой доступ к классам, свойствам и функциям движка. Players and world objects, plus direct access to engine classes, properties and functions.

Objects

get_objects()
Возвращает массив указателей на все объекты (акторы) в мире. Returns an array of pointers to all objects (actors) in the world.
find_object(class_name, [owner])
Первый живой объект класса class_name или его наследника, иначе null. Ищет по всем объектам игры (не только по акторам карты) и кэширует результат, поэтому можно звать каждый кадр: find_object("HUD"). С owner — только объекты внутри него, например компонент своего персонажа: find_object("CharacterMovementComponent", get_local_player()). Если объект достижим от контроллера или персонажа, проще get_property(pc, "MyHUD"). The first live object of class class_name or a subclass, or null. Searches every game object (not only map actors) and caches the result, so it is fine every frame: find_object("HUD"). With owner, only objects inside it, e.g. a component of your own pawn: find_object("CharacterMovementComponent", get_local_player()). If the object is reachable from the controller or pawn, get_property(pc, "MyHUD") is simpler.
find_objects(class_name, [owner])
Массив всех живых объектов класса или его наследников. Полный перебор без кэша: не вызывайте каждый кадр. An array of every live object of the class or its subclasses. A full scan with no cache: don't call it every frame.
get_object_name(obj)
Возвращает имя объекта или актора по его указателю. Returns the name of the object or actor by its pointer.
get_local_player()
Возвращает указатель на локального игрока или null. Returns the pointer to the local player pawn, or null.
get_my_controller()
Возвращает указатель на локальный контроллер игрока или null. Returns the pointer to the local player controller, or null.
get_targets()
Возвращает массив указателей на все валидные цели (игроков/акторов). Returns an array of pointers to all valid targets (players/actors).
get_name(ptr)
Возвращает имя сущности по ее указателю. Returns the name of the actor by its pointer.
get_location(ptr)
Возвращает 3D позицию объекта {x, y, z}. Returns the 3D location {x, y, z} of the actor.
get_health(ptr)
Возвращает количество здоровья актора. Returns the health value of the actor.
is_friend(ptr)
Проверяет, находится ли актор в списке друзей (true/false). Returns true if the actor is on your friend list.

Engine

Прямая работа с движком игры и вызовами функций. Low-level engine interactions and direct function calling.

find_class(name)
Находит указатель на класс по его названию. Finds a class pointer by name (e.g., "DamageRegular").
call_function(obj_ptr, func_name, args_array)
Вызывает любую SDK функцию. Calls any SDK function.
get_property(obj_ptr, prop_name)
Читает любое свойство/переменную из объекта. Можно путь через точку: get_property(pc, "MyHUD.bShowHUD") — промежуточные поля должны быть объектами или структурами. Reads any variable from an object by its SDK name. A dotted path works too: get_property(pc, "MyHUD.bShowHUD") — the steps before the last must be objects or structs.
set_property(obj_ptr, prop_name, value)
Записывает значение в любую переменную объекта. Путь через точку тоже работает: set_property(pc, "MyHUD.bShowHUD", false). Writes a value to any object variable. A dotted path works too: set_property(pc, "MyHUD.bShowHUD", false).
Supported Property Types / Поддерживаемые типы свойств
get_property и set_property поддерживают все типы свойств Unreal Engine: get_property and set_property support all Unreal Engine property types:
  • FloatProperty, DoubleProperty - числа с плавающей точкойfloating point numbers → number
  • Int8/16/32/64Property, UInt16/32/64Property, ByteProperty - целочисленные типыinteger types → number
  • BoolProperty - логическое значениеboolean → boolean
  • NameProperty (FName), StrProperty (FString), TextProperty (FText) - строкиstrings → string
  • EnumProperty - перечисление (по underlying типу)enum (via underlying type) → number
  • ObjectProperty, ClassProperty, WeakObjectProperty, SoftObjectProperty, InterfaceProperty - указатели на объектыobject pointers → pointer / null
  • StructProperty - структуры (Vector, Rotator, Color, Transform и любые другие — рекурсивно по полям)structs (Vector, Rotator, Color, Transform and any other — recursively by fields) → object
  • ArrayProperty - массивы (TArray, элементы рекурсивно распаковываются)arrays (TArray, elements unpacked recursively) → Array
  • Неизвестные типыUnknown types → ArrayBuffer (сырые байтыraw bytes)

Menu

Управление встроенным меню софта, создание вкладок и интерактивных элементов. Menu interaction, tab creations, sliders, comboboxes and layout bindings.

register_tab(name)
Создает новую главную вкладку в сайдбаре меню. Creates a new main tab in the menu sidebar.
register_section(tab_name, section_name)
Создает подсекцию внутри вкладки. Creates a sub-section inside a tab.
add_checkbox(tab_name, section_name, label, default_value)
Добавляет интерактивный чекбокс (boolean). Adds a custom checkbox setting element (boolean).
add_slider(tab_name, section_name, label, default, min, max)
Добавляет ползунок для выбора числовых значений с плавающей запятой (number). Adds a slider for numerical configuration (number).
add_combo(tab_name, section_name, label, default_index, items_array)
Добавляет выпадающий список вариантов. Возвращает индекс выбранного элемента (number). Adds a dropdown selection element. Returns selected element index (number).
add_colorpicker(tab_name, section_name, label, r, g, b, a)
Добавляет палитру выбора цвета. Возвращает объект вида {r, g, b, a}. Adds an interactive color picker element. Returns a color object {r, g, b, a}.
add_button(tab_name, section_name, label, callbackFunction)
Добавляет интерактивную кнопку, которая вызывает переданную функцию при клике. Adds a clickable button element that triggers the specified callback function name.
add_inputbox(tab_name, section_name, label, defaultText, maxLength)
Добавляет поле ввода текста. Возвращает строковое значение (string). Adds a text input box. Returns current text sequence (string).
get_ui_value(label)
Возвращает текущее состояние элемента UI или Config переменной меню. Работает как с кастомными вкладками, так и с основными переменными (например "God Mode", "Aimbot", "Speed Hack" и т.д.). Типы: boolean, number, string или object. Returns the current value of a UI element or main menu Config variable. Works with both custom tabs and built-in variables (e.g. "God Mode", "Aimbot", "Speed Hack", etc.). Types: boolean, number, string, or object.
set_ui_value(label, value)
Устанавливает значение элемента UI или Config переменной меню. Позволяет программно изменять любые настройки из скрипта, включая основные переменные меню. Sets the value of a UI element or main menu Config variable. Allows programmatically changing any setting from scripts, including main menu variables.

System

Выход за пределы игры: HTTP-запросы и вызов любых функций Windows из DLL. Reaching outside the game: HTTP requests and calling any Windows function from a DLL.

Console

print(a, b, ...)
Пишет строку в консоль игры (F2). Аргументы через пробел, объекты — как JSON, "\n" делит на строки. Работает и в главном меню. Writes a line to the game console (F2). Arguments are joined by spaces, objects printed as JSON, "\n" splits lines. Works in the main menu too.
console.log(a, b, ...)
То же, что print. Same as print.

Network

http.download(url, method, postData, headers)
Выполняет HTTP запрос. url — адрес запроса, method — метод (по умолчанию "GET"), postData — тело запроса для POST, headers — дополнительные заголовки. Возвращает строку с ответом сервера или null при ошибке. Performs an HTTP request. url — request URL, method — HTTP method (default "GET"), postData — body for POST requests, headers — additional headers. Returns response string or null on error.

Native FFI

Динамический Foreign Function Interface (FFI) для прямого взаимодействия с Windows API подсистемами. Dynamic Foreign Function Interface (FFI) to interact directly with low-level Windows API subsystems.

native.define(name, dll, function, returnType, ...argTypes)
Регистрирует внешнюю C-функцию из указанной DLL библиотеки для последующего вызова. Registers an exported C-function from a specified DLL library for subsequent execution.
native.call(name, ...args)
Вызывает ранее определенную Windows API функцию по её зарегистрированному имени. Invokes a previously defined Windows API function by its registered configuration name.
Supported Types / Поддерживаемые типы данных
При связывании аргументов и возвращаемых значений используйте строго следующие строковые типы: When mapping arguments and return types, strictly use the following syntax values:
  • "void" - отсутствие возвращаемого значенияno return value
  • "int" - целочисленное значение типа intstandard integer values
  • "ptr" / "pointer" - указатели на области памяти или структурыmemory addresses and pointers
  • "string" / "str" - строковые значения (C-style char pointer)string sequences
  • "float" - число с плавающей точкой (одинарная точность)floating point numbers
  • "double" - число с плавающей точкой (двойная точность)double precision floats

SDK

Классы, структуры и enum'ы игры. Найдите поле или функцию — готовый вызов get_property / set_property / call_function появится сразу. Game classes, structs and enums. Find a field or function and get a ready get_property / set_property / call_function call.

 Native Windows API FFI Usage





native.define("MessageBoxA", "user32.dll", "MessageBoxA", "int", "ptr", "string", "string", "int");
native.define("Beep", "kernel32.dll", "Beep", "int", "int", "int");
native.define("Sleep", "kernel32.dll", "Sleep", "void", "int");
native.define("GetTickCount", "kernel32.dll", "GetTickCount", "int");

function showMessage(text, title) {
    return native.call("MessageBoxA", null, text, title, 0);
}

function playBeep(freq, duration) {
    native.call("Beep", freq, duration);
}

function sleep(ms) {
    native.call("Sleep", ms);
}

function getTickCount() {
    return native.call("GetTickCount");
}

showMessage("Hello from native FFI!", "Test");

playBeep(1000, 200);

function on_render() {
    var ticks = getTickCount();
    draw_text(10, 140, 255, 255, 0, 255, "System ticks: " + ticks);
}

 Custom Shader & Console





var fx = null;

function on_load() {
    fx = shader_create([
        "float4 main(PSIn i) : SV_Target {",
        "    float2 uv = i.ScreenUV;",
        "    uv.x += sin(uv.y * 40.0 + Time * 3.0) * 0.003 * Params[0].x;",
        "    float3 c = Scene.Sample(Linear, uv).rgb;",
        "    float3 tint = 0.5 + 0.5 * cos(Time + i.UV.xyx * 6.0 + float3(0, 2, 4));",
        "    return float4(lerp(c, c * tint * 1.5, 0.5), 1.0);",
        "}"
    ].join("\n"));
    print("shader id:", fx);
}

function on_render() {
    if (!fx) return;
    var s = screen_size();
    shader_draw(fx, s.x / 2 - 300, s.y / 2 - 200, 600, 400, [1.5]);
}








 Space Sky (shader_attach on the sky)


Космос вместо неба. Скрипт находит Ultra_Dynamic_Sky_C, берёт его купол Ultra_Dynamic_Sky_Sphere и ставит на него шейдер. Сохраните оба файла в C:\Night\scripts\. Пока включён свой Sky Shader клиента, купол остаётся ему.Space instead of the sky. The script finds Ultra_Dynamic_Sky_C, takes its dome Ultra_Dynamic_Sky_Sphere and puts the shader on it. Save both files to C:\Night\scripts\. While the client's own Sky Shader is on, the dome is left to it.







// Space sky: the same trick as the client's Sky Shader, done from a script with shader_attach.
// The sky dome gets a flat key material in one pure color; the shader (sky_space.hlsl) runs only on pixels
// of that color, so grass, water or the sun never turn into space.
// While the client's own Sky Shader (or sky image) is on, the dome is left to it: the status says so.

var TAB = "Space Sky", SEC = "Settings";

var fx = null;      // shader
var sky = null;     // Ultra Dynamic Sky actor
var attached = null; // attachment on its dome
var frame = 0;

function on_load() {
    register_tab(TAB);
    register_section(TAB, SEC);
    add_checkbox(TAB, SEC, "Enable Space Sky", true);
    add_slider(TAB, SEC, "Brightness", 1.0, 0.1, 3.0);
    add_slider(TAB, SEC, "Stars", 1.0, 0.0, 2.0);
    add_slider(TAB, SEC, "Nebula", 1.0, 0.0, 2.0);
    add_slider(TAB, SEC, "Nebula Color", 0.0, -0.5, 0.5);

    fx = shader_load("sky_space.hlsl");
    print("[Space Sky] shader:", fx);
}

function detach() {
    if (attached) shader_detach(attached);
    attached = null;
    sky = null;
}

// Twice a second: the sky actor (a new map has a new one), attached or detached as the checkbox says
function updateSky(enabled) {
    var found = enabled && fx ? find_object("Ultra_Dynamic_Sky_C") : null;
    if (found == sky) return;
    detach();
    if (!found) return;
    var dome = get_property(found, "Ultra_Dynamic_Sky_Sphere");
    if (!dome) return;
    sky = found;
    attached = shader_attach(fx, dome);
    print("[Space Sky] attached:", attached);
}

function on_render() {
    var enabled = get_ui_value("Enable Space Sky");
    if (frame++ % 30 == 0) {
        updateSky(enabled);
        if (attached && frame % 300 == 1) print("[Space Sky]", shader_attach_status(attached));
    }
    if (!attached) return;
    shader_attach_params(attached, [
        get_ui_value("Brightness"), get_ui_value("Stars"), get_ui_value("Nebula"), get_ui_value("Nebula Color")
    ]);
}

function on_unload() {
    detach(); // unloading also puts the dome back by itself, this is just tidy
}








 Energy Body on Your Dino (shader_attach on yourself)


Свой дино из текущей энергии с контуром. На shader_attach передаётся весь персонаж (get_local_player()), поэтому шейдер ложится и на Custom Model. После респавна скрипт сам цепляется к новому персонажу. Пока включён свой Model Shader клиента, дино остаётся ему.Your dino made of flowing energy with an outline. The whole pawn (get_local_player()) goes to shader_attach, so the shader lands on the Custom Model too. After a respawn the script attaches to the new pawn by itself. While the client's own Model Shader is on, the dino is left to it.







// Energy body on your own dino: dino_energy.hlsl put on get_local_player() with shader_attach.
// The whole pawn is passed (an actor): every mesh on it gets the shader, the custom model too.
// While the client's own Model Shader is on, the dino is left to it: the status says so.

var TAB = "Dino Energy", SEC = "Settings";
var fx = null, att = null, pawn = null, frame = 0;

function on_load() {
    register_tab(TAB);
    register_section(TAB, SEC);
    add_checkbox(TAB, SEC, "Enable Energy", true);
    add_slider(TAB, SEC, "Brightness", 1.0, 0.1, 3.0);
    add_slider(TAB, SEC, "Speed", 1.0, 0.0, 4.0);
    add_slider(TAB, SEC, "Hue", 0.55, 0.0, 1.0);
    add_checkbox(TAB, SEC, "Rainbow", false);
    add_slider(TAB, SEC, "Outline", 1.0, 0.0, 2.0);
    add_slider(TAB, SEC, "Scan Lines", 0.5, 0.0, 1.0);
    fx = shader_load("dino_energy.hlsl");
}

function detach() {
    if (att) shader_detach(att);
    att = null;
    pawn = null;
}

function on_render() {
    var enabled = get_ui_value("Enable Energy");
    // Twice a second: a respawn or a new dino is a new pawn, attach to that one
    if (frame++ % 30 == 0) {
        var now = enabled && fx ? get_local_player() : null;
        if (now != pawn) {
            detach();
            if (now) { pawn = now; att = shader_attach(fx, now); }
        }
    }
    if (!att) return;
    shader_attach_params(att, [
        get_ui_value("Brightness"), get_ui_value("Speed"), get_ui_value("Hue"), get_ui_value("Rainbow") ? 1 : 0,
        get_ui_value("Outline"), get_ui_value("Scan Lines")
    ]);
}

function on_unload() {
    detach();
}








 Hologram on Other Players (shader_attach on objects)


Три ближайших игрока из get_targets() становятся голограммами; раз в секунду список пересчитывается, лишние снимаются через shader_detach. Так же можно ставить шейдер на любой актёр или меш-компонент: find_object, get_property. Одновременно — до 4 объектов на все скрипты.The three nearest players from get_targets() become holograms; the list is rebuilt every second and the ones dropped get shader_detach. Any actor or mesh component works the same way: find_object, get_property. Up to 4 objects at a time across all scripts.







// Hologram on other players: players_hologram.hlsl on the 3 nearest ones (shader_attach takes 4 objects at a
// time; one is left free for another script, e.g. the sky). Picked again every second as players move.

var TAB = "Hologram", SEC = "Settings";
var MAX = 3;
var fx = null, frame = 0;
var on = [];   // { pawn, att } currently attached

function on_load() {
    register_tab(TAB);
    register_section(TAB, SEC);
    add_checkbox(TAB, SEC, "Enable Hologram", true);
    add_colorpicker(TAB, SEC, "Color", 0, 200, 255, 255);
    add_slider(TAB, SEC, "Body Fill", 0.4, 0.0, 1.0);
    add_slider(TAB, SEC, "Brightness", 1.2, 0.2, 3.0);
    add_slider(TAB, SEC, "Max Distance (m)", 200, 20, 1000);
    fx = shader_load("players_hologram.hlsl");
}

function distanceTo(a, b) {
    var dx = a.x - b.x, dy = a.y - b.y, dz = a.z - b.z;
    return Math.sqrt(dx * dx + dy * dy + dz * dz) / 100; // unreal units are centimeters
}

function find(pawn) {
    for (var i = 0; i < on.length; i++) if (on[i].pawn == pawn) return i;
    return -1;
}

// The nearest players in range; attach the new ones, detach the ones no longer picked
function pick() {
    var me = get_local_player();
    var myPos = me ? get_location(me) : null;
    var want = [];
    if (get_ui_value("Enable Hologram") && fx && myPos) {
        var list = get_targets(), maxDist = get_ui_value("Max Distance (m)");
        for (var i = 0; i < list.length; i++) {
            if (list[i] == me) continue;
            var pos = get_location(list[i]);
            if (!pos) continue;
            var d = distanceTo(pos, myPos);
            if (d <= maxDist) want.push({ pawn: list[i], dist: d });
        }
        want.sort(function (a, b) { return a.dist - b.dist; });
        want = want.slice(0, MAX);
    }
    var keep = [];
    for (var k = 0; k < on.length; k++) {
        var still = false;
        for (var w = 0; w < want.length; w++) if (want[w].pawn == on[k].pawn) still = true;
        if (still) keep.push(on[k]); else shader_detach(on[k].att);
    }
    on = keep;
    for (var n = 0; n < want.length; n++) {
        if (find(want[n].pawn) >= 0) continue;
        var att = shader_attach(fx, want[n].pawn);
        if (att) on.push({ pawn: want[n].pawn, att: att });
    }
}

function on_render() {
    if (frame++ % 60 == 0) pick();
    if (on.length == 0) return;
    var c = get_ui_value("Color");
    var me = get_local_player();
    var myPos = me ? get_location(me) : null;
    for (var i = 0; i < on.length; i++) {
        var pos = get_location(on[i].pawn);
        var dist = pos && myPos ? distanceTo(pos, myPos) : 0;
        shader_attach_params(on[i].att, [
            c.r / 255, c.g / 255, c.b / 255, get_ui_value("Body Fill"),
            dist, get_ui_value("Brightness")
        ]);
    }
}

function on_unload() {
    for (var i = 0; i < on.length; i++) shader_detach(on[i].att);
    on = [];
}
